# reactive-ecommerce-platform

A production-grade enterprise backend built using Java 21, Spring Boot, Spring WebFlux, Kafka, Redis, PostgreSQL, Kubernetes, Docker and AWS.

---

## Goal

This repository documents my journey of building an enterprise-scale reactive e-commerce platform from scratch.

The project focuses on:

- Reactive Programming
- Microservices
- Event-Driven Architecture
- High-Level Design
- Low-Level Design
- Security
- Performance
- DevOps
- Kubernetes
- AWS
- CI/CD
